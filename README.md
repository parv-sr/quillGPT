# tinyGPT - A pretrained transformer

tinyGPT is a pretrained transformer trained on Andrej Karpathy's `tinyshakespeare` dataset.
It is trained to generate shakespeare-like text.

### Model features:

#### 4 transformer blocks
#### Self-attention based on "Attention is all you need" (Vaswani et al, Google 2017)
#### GeLU Activation
#### GPT-3 style decoder-only architecture
#### Training dataset: `tinyshakespeare` by Andrej Karpathy (https://github.com/karpathy/char-rnn)
